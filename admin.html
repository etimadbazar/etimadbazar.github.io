1GitHub se connect karein

Yeh panel aap ki website ki files seedha GitHub par badalta hai. Is ke liye ek dafa GitHub "token" (chaabi) chahiye. Token sirf isi browser mein mehfooz rehta hai, website par kisi ko nazar nahi aata. Kisi ke saath share mat karein.

Token kaise banayein? (ek dafa ka kaam)
  1. GitHub par profile tasveer → Settings → bilkul neeche Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. Token name: store admin. Expiration: 1 saal (ya jitna chahein).
  4. Resource owner mein etimadbazar chunein.
  5. Repository access → Only select repositories → etimadbazar.github.io.
  6. Permissions → Repository permissions → Contents → Read and write.
  7. Generate token dabayein, token copy karein aur neeche paste karein.
  8. Agar GitHub "approval" maange: organization etimadbazar → Settings → Personal access tokens → Pending requests → Approve.

Ab apna Admin password banayein. Aage se har dafa sirf yehi password maanga jayega.

⚙️ Orders system setup

Orders aap ke apne Google Sheet mein jama honge (free), aur har order par aap ko WhatsApp aur email aayegi. Yeh setup sirf ek dafa karna hai, taqreeban 10 minute.

Qadam 1: WhatsApp alert ki chaabi (CallMeBot)

  1. CallMeBot ka WhatsApp number phone mein save karein. Number in ki official site se lein: callmebot.com (us waqt yeh +34 684 783 708 tha).
  2. Us number par apne usi WhatsApp se jis par orders chahiye, yeh message bhejein: I allow callmebot to send me messages
  3. 2 minute mein jawab aayega: "Your APIKEY is 123456". Woh number neeche likhein.

Store ki settings mein WhatsApp number sahi hona chahiye, warna pehle woh badal kar save karein. CallMeBot sirf aap ko (apne number par) message bhejta hai, customer ko nahi.

Qadam 2: Google Sheet aur code

  1. Is link se naya Google Sheet banayein: sheets.new. Upar naam rakhein: Etimad Bazar Orders.
  2. Menu mein Extensions → Apps Script.
  3. Wahan jo code likha hai sab mita dein, phir neeche wala button daba kar code copy karein aur wahan paste karein. 💾 Save dabayein.
  4. Upar function list mein setup chun kar ▶ Run dabayein. Google ijazat maangega: Review permissions → apna account → Advanced → Go to … (unsafe) → Allow. (Yeh aap ka apna code hai, is liye Google aisa likhta hai.)
Copy na ho to code yahan se select karein

Qadam 3: Web app banayein

  1. Apps Script mein upar daayen Deploy → New deployment.
  2. ⚙️ (Select type) → Web app.
  3. Execute as: Me  ·  Who has access: Anyone
  4. Deploy dabayein aur jo Web app URL mile (https://script.google.com/macros/s/…/exec) usay copy karein.

Qadam 4: Yahan jod dein

Baad mein code badlein (maslan nayi CallMeBot key), to Apps Script mein Deploy → Manage deployments → ✏️ → Version: New version → Deploy karein. URL wahi rahega.
